# 01-Study

## 🎯 Goal
To organize, track, and retain knowledge from academic courses, technical tutorials, books, and continuous self-learning.

## 📁 Subfolder Structure
*(Recommended structure for this section)*
- `courses/`: Structured online courses, syllabi, notes, and certificates.
- `books/`: Reading notes, summaries, and key takeaways from technical and non-technical books.
- `topics/`: Subject-specific deep dives (e.g., mathematics, computer science, languages).
- `cheatsheets/`: Quick reference guides and code snippets.
