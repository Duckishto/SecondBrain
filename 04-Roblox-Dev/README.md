# 04-Roblox-Dev

## 🎯 Goal
To design, script, and publish immersive games and experiences on the Roblox platform using Luau and Roblox Studio.

## 📁 Subfolder Structure
*(Recommended structure for this section)*
- `gdd/`: Game Design Documents detailing gameplay loops, monetization, and UI/UX wireframes.
- `scripts/`: Reusable Luau modules, client/server scripts, and system architectures.
- `assets/`: 3D models, audio notes, animations, and UI asset tracking.
- `logs/`: Development logs, update changelogs, and bug tracking.
